Лабораторная работа №1

Описание базы данных Основная цель — предоставить возможность пользователю эффективно управлять своими задачами, контролировать сроки выполнения, устанавливать приоритеты и отслеживать затраченное время на каждую задачу.

  1. Таблица User (Пользователь)

Поля: id: Уникальный идентификатор пользователя. username: Имя пользователя, используемое для входа и отображения. email: Адрес электронной почты для уведомлений и связи. hashed_password: Хэш пароля для безопасного хранения учетных данных. registered_at: Дата и время регистрации пользователя (дополнительное поле). Назначение: Хранит информацию о каждом пользователе, что позволяет индивидуально настраивать задачи и управлять ими. 2. Таблица Task (Задача)

Поля: id: Уникальный идентификатор задачи. title: Название задачи, кратко описывающее суть работы. description: Подробное описание задачи. deadline: Срок выполнения задачи, что помогает организовать время и отслеживать приближение дедлайна. priority: Приоритет задачи, выраженный числовым уровнем — чем выше значение, тем важнее задача. user_id: Внешний ключ, связывающий задачу с конкретным пользователем (один пользователь может иметь несколько задач). Назначение: Позволяет создавать задачи с описанием, дедлайнами и приоритетами. Это центральная сущность, вокруг которой строится функциональность тайм-менеджмента. 3. Таблица TimeEntry (Учёт времени)

Поля: id: Уникальный идентификатор записи учёта времени. task_id: Внешний ключ, связывающий запись с определённой задачей (одна задача может иметь несколько записей). duration: Затраченное время на выполнение задачи (например, в секундах или минутах). created_at: Дата и время создания записи, что позволяет вести хронологический учёт времени. Назначение: Обеспечивает возможность отслеживать, сколько времени было потрачено на выполнение каждой задачи. Это важный компонент анализа эффективности работы и планирования расписания. 4. Таблица Tag (Метка)

Поля: id: Уникальный идентификатор метки. name: Название метки, позволяющее категоризировать задачи по тематике или типу работы. Назначение: Позволяет классифицировать задачи, например, по типу деятельности или по важности, что способствует быстрому поиску и анализу данных. 5. Таблица TaskTag (Ассоциативная сущность)

Поля: task_id: Внешний ключ, указывающий на задачу. tag_id: Внешний ключ, указывающий на метку. note: Дополнительное поле, позволяющее сохранить комментарий или степень важности метки для конкретной задачи. Назначение: Реализует связь многие-ко-многим между задачами и метками, позволяя одной задаче иметь несколько меток, а одной метке — применяться к разным задачам. Дополнительное поле note предоставляет гибкость для описания специфики связи.
